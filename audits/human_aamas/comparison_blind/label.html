AAMAS boxed comparisons (blind)

What you are doing

Each item is a crop of a results table from an AAMAS paper with one cell outlined by a thin red box. Read the table and the paper and answer the questions on the right. Nothing on this page tells you what any program or model read from the table: the answers must come from the table and the paper alone.

How

  1. Enter your annotator ID at the top (the ID you were given; never a name). Answers autosave in this browser under that ID.
  2. Read the crop. Click it to zoom. If the crop is not enough (caption cut off, header missing), use Open the full paper: it opens the public PDF at the right page.
  3. For the error-bar meaning and the run count, always open the full paper and search it (Ctrl+F: seed, run, trial, repeat, std, standard error, confidence). Do not decide them from the crop.
  4. The runner-up is the best value among the non-bold cells of the same group, in the direction you chose (highest if higher is better).
  5. Write unclear (or pick unclear) whenever you cannot tell; never guess. none means the paper does not state it.
  6. Enter moves to the next question, Ctrl+Enter saves and moves to the next item, Alt+←/→ moves between items.
  7. When you stop, press Export CSV and send the file unchanged. To continue on another computer, use Resume from CSV.
Start with the item set Core 100. A second annotator only does the set Double-annotation 30. Do not open any other file of the project while labelling.
