AAMAS pages: every single-bold group

What you are doing

Each item is one whole page of an AAMAS paper, drawn at random. List every table on the page and, in every results table, every group that has exactly one bold cell. A page can have none: say so explicitly.

Definitions

  • Results table: a table of measured outcomes (scores, rewards, errors, times) of methods or settings. Not hyperparameters, dataset statistics, notation or pseudocode.
  • Orientation: column if the methods are rows and you compare down a column; row if the methods are columns.
  • Group: one column (column orientation) or one row (row orientation) of numbers in which methods are compared. If the table is split into blocks by rules, each block's column is a separate group.
  • Eligible group: exactly one bold cell, at least one non-bold number, and the bold number is strictly the best in the direction the metric is read (choose tie or no otherwise). List the other single-bold groups too, with the right answer in Bold is best?
  • Bold rule: if the caption says bold marks something other than the single best (top-3, significance, the authors' method), pick that option.

How

  1. Enter your annotator ID. Answers autosave in this browser under that ID.
  2. Add each table (+ Add table), then each group (+ Add group). With a group selected, click its bold cell on the page to record where it is.
  3. Type the bold value exactly as printed (85.20, keep %). The group label is the row or column header (e.g. "Hopper", "Acc. (%)").
  4. Set the page status last. A page with no eligible group needs This page has NO eligible group, and a short note on what is there.
  5. Use Open the full paper when the page image is unclear. Export the CSV when you stop; resume with Resume from CSV.
